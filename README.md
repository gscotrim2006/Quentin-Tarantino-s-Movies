Uma página web temática dedicada à filmografia e ao universo cinematográfico do diretor Quentin Tarantino, desenvolvida com HTML5 e CSS3 puras.

---

## Sobre o Projeto

Este projeto consiste em uma interface web informativa desenvolvida para apresentar obras marcantes do cineasta Quentin Tarantino. O objetivo principal foi exercitar a estruturação semântica e a estilização visual com foco na estética dos filmes do diretor.

### 🎯 Objetivos de Aprendizado
- Estruturação semântica de páginas utilizando **HTML5**.
- Estilização, tipografia e layout responsivo com **CSS3**.
- Organização e boas práticas na estruturação de projetos front-end.

---

## Tecnologias Utilizadas

- **HTML5**: Estrutura e marcação semântica dos elementos.
- **CSS3**: Estilização, esquemas de cores, tipografia e layout.

---

## Como Executar Localmente

Para clonar e rodar este projeto em sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/GuisoBiso67/Quentin-Tarantino-s-Movies.git
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd Quentin-Tarantino-s-Movies
   ```

3. **Abra o projeto:**
   - Basta dar um duplo clique no arquivo `index.html` ou abri-lo diretamente em seu navegador preferido.
   - Caso utilize o VS Code, você pode usar a extensão **Live Server** para rodar um servidor local.
